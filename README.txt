STUDENT ART BLOG - QUICK START

1. Open index.html in a browser to view the site.
2. To personalize it:
   - Change "My Art Blog" to the student's name or blog title in each HTML file.
   - Replace [Student Name] on about.html.
   - Put artwork images inside assets/images.
   - In each HTML file, replace placeholder image names with your own file names.
3. To add a new post:
   - Copy one of the post pages.
   - Rename it, for example: post-self-portrait.html
   - Change the title, image, assignment, process, and reflection.
   - Add a new card on index.html that links to the new post.
4. To publish online:
   - Upload the folder to GitHub Pages, Netlify, or your college's required web platform.

Suggested post format:
- Title
- Date
- Image of artwork
- Assignment description
- Materials used
- Process notes
- Reflection: What worked? What would I improve next time?
