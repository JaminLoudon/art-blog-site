Project 1: Value Study

Assignment: Create an artwork focused on value, contrast, and light source.

Process: I began with rough sketches, then chose one composition to develop. I focused on where the light would hit and where the darkest shadows would fall.

Reflection: This project helped me understand how value creates depth. Next time, I want to improve my transitions between midtones and shadows.
